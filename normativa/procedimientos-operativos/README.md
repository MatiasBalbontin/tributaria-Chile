# Procedimientos Operativos - Matrices Técnicas y DDJJ

Lógica de validación sistemática del SII, instrucciones de llenado y matrices de cruces de información en declaraciones juradas.

## Contenido

### `matrices-ddjj/`
Matrices de Declaraciones Juradas que validan coherencia de datos reportados en:

- **F1947:** Declaración impuesto a la renta (PJ)
- **F1948:** Declaración impuesto a la renta (PN)
- **F1926:** Declaración de IVA
- **F1909:** Declaración complementaria de impuesto a la renta
- Otras DDJJ relevantes

**Estructura:** `matrices-ddjj/F1947-validacion-cruces.md`

**Contenido:**
- Campos clave
- Reglas de cuadratura
- Errores comunes
- Prevención de observaciones

### `formulario-22/`
Guía técnica: Formulario 22 (Declaración de Renta) - Operación Renta anual.

**Secciones:**
- Instrucciones por régimen tributario
- Concordancia con DDJJ previas
- Cuadratura balance vs. DDJJ
- Trazabilidad de datos

### `validacion-sii/`
Lógica de validación e-filing: Cruce informático SII, reglas de bloqueo, matrices de coherencia.

**Crítico para:**
- Prevenir bloqueos masivos de devoluciones
- Control total sobre trazabilidad de datos
- Anticipar observaciones

---

**Importancia:** El cruce SII no se basa en balance, sino en coherencia sistemática de DDJJ.

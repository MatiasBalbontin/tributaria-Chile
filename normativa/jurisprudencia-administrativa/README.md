# Jurisprudencia Administrativa del SII

Pronunciamientos vinculantes del Servicio de Impuestos Internos que fijan interpretación oficial de leyes tributarias.

## Contenido

### `oficios-sii/`
Oficios Ordinarios: Respuestas a consultas tributarias específicas (reorganizaciones, retiros, gastos, precios de transferencia).

**Estructura:** `oficios-sii/AAAA/oficio-N-descripcion.md`

Ejemplo: `oficios-sii/2024/oficio-1234-reorganizacion-empresarial.md`

**Contenido:** 
- Consulta original
- Criterio SII
- Aplicabilidad
- Referencias a leyes

### `circulares-sii/`
Circulares: Documentos técnicos de instrucción general sobre aplicación de leyes o reformas tributarias.

**Estructura:** `circulares-sii/AAAA/circular-N-tema.md`

Ejemplo: `circulares-sii/2024/circular-15-deducciones-2024.md`

**Contenido:**
- Materia de la circular
- Instrucciones SII
- Ejemplos de aplicación
- Fecha de vigencia
